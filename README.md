# Multi-Page Web Project

A multi-page web project developed using HTML, CSS, and JavaScript.

## Technologies

- HTML5
- CSS3
- JavaScript

## Features

- Multi-page website structure
- Custom CSS styling
- Interactive forms
- JavaScript-based form functionality
- Image and multimedia integration

## Project Structure

- `index.html` – Main page
- `rose2.html` – Additional webpage
- `rose3.html` – Additional webpage
- `form.html` – Interactive form
- `rose.css` – Website styling
- `form.css` – Form styling
- `form.js` – JavaScript functionality
